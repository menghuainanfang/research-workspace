# 二维Burgers：空间半离散与时间推进

打开[独立二维演示](plane.html)，在固定二维平面上观察高值区域的输运与平滑。可选择ν=0.01、0.02、0.05、0.1；切换黏性保留当前物理时刻，右图可显示立体曲面或另一黏性的平面对照。

## 模型与离散

二维标量方程u_t+u(u_x+u_y)=νΔu，单位正方形、零源项、零Dirichlet边界。初值是左下方的光滑局部峰，归一化峰值1。所有选项共享规整固定网格：1089节点、2048三角形；P1有限元、后向Euler、Δt=0.01，80个物理步至t=0.8。

空间半离散为M dU/dt+νKU+C(U)U=0。默认采用[参考文档](https://wnesm678i4.feishu.cn/wiki/VLg4wtFGpiN2GzkqsYOcwL3wnHc)标量主程序的显式输运、隐式扩散格式；另有文档方案二和全隐式对照。

|时间格式|内点离散方程|每步计算|
|---|---|---|
|显式输运 / 隐式扩散|(M/Δt+νK)Uⁿ⁺¹=MUⁿ/Δt−C(Uⁿ)Uⁿ|一次线性求解|
|新值乘旧梯度|(M/Δt+νK+R(Uⁿ))Uⁿ⁺¹=MUⁿ/Δt|一次线性求解|
|全隐式Picard|(M/Δt+νK+C(Uⁿ⁺¹))Uⁿ⁺¹=MUⁿ/Δt|Picard更新至非线性残量≤10⁻⁹|

Rᵢⱼ(Uⁿ)=∫(∂ₓuₕⁿ+∂ᵧuₕⁿ)φᵢφⱼ，是由旧梯度决定的反应型质量矩阵。ν=1/Re。FEALPy组装M和K；P1输运项使用精确单元公式，并与FEALPy积分结果核对。

## 页面交互

- 黏性选择、物理时间播放与滑块；固定网格及局部输运方向开关。
- 平面颜色与高度使用固定比例，不同黏性可按同一时刻对照。
- 四种黏性的峰值和归一化能量曲线；点击曲线定位实际物理步。
- 时间格式面板显示空间半离散、时间层组合和矩阵方程；切换格式保留物理时刻。
- “看本步怎样求解”：重演实际求解阶段、相对上一时刻的增量、格式残量变化。
- 点击固定节点，展开其P1质量、扩散、输运系数和实际节点方程。边界节点直接展示零Dirichlet条件。
- 能量面板区分黏性耗散、时间离散项和有符号输运功，核对离散能量平衡。

## 验证

12组共960个物理步通过所选格式残量及零边界检查。文档两种格式的最大线性残量小于5×10⁻¹⁶；全隐式最大非线性残量小于10⁻⁹，每步最多7次Picard更新。浏览器节点行与Python求解矩阵逐项一致；每个物理帧等于保存的最终解。能量满足Eⁿ⁺¹−Eⁿ+‖Uⁿ⁺¹−Uⁿ‖²_M/2+Δtν(Uⁿ⁺¹)ᵀKUⁿ⁺¹+Δt(Uⁿ⁺¹)ᵀT≈0，其中T为所选格式实际采用的输运向量。输运功可以正也可以负。数值汇总见[validation_2d.json](validation_2d.json)。

独立8×8网格、正弦初值、ν=.02、T=.1的时间加密测试，以同一空间半离散系统的高精度DOP853解为参考：

|格式|Δt=.01误差|Δt=.005误差|Δt=.0025误差|
|---|---:|---:|---:|
|显式输运 / 隐式扩散|.023179|.011536|.005752|
|新值乘旧梯度|.022721|.011289|.005625|
|全隐式Picard|.020731|.010539|.005313|

误差为内部节点向量二范数，步长减半后误差约减半，符合一阶时间精度。下表为全隐式对照的最终峰值：

|ν|t=0.8峰值|
|---:|---:|
|0.01|0.295753|
|0.02|0.191028|
|0.05|0.079925|
|0.1|0.029043|

## 复现与文件

在研究仓库根目录，用移动网格Python环境运行：

```powershell
& 'D:/桌面/movingmesh/移动网格/.venv/Scripts/python.exe' '学习练手项目/burgers-lab/solve_2d.py'
```

只修改页面后可追加--render-only。plane_template.html与plane_view.js为页面源文件；solve_2d.py生成数据，schemes_2d.py实现三种时间格式；results_2d.json.gz包含全部场与求解记录。运行test_schemes_2d.py验证组装及时间精度，node --test plane_view.test.cjs验证页面公式、求解记录及能量平衡。plane.html内置压缩数据与KaTeX，可在新版Edge/Chrome离线回放。统一包由移动网格/tools/package_presentation.py生成。

## 适用范围

当前采用固定网格，聚焦标量Burgers半离散和时间推进。显式输运格式受时间步稳定性限制；当前数据不代表任意步长都稳定。算例没有解析解，残量与能量检查不替代空间误差研究。低黏性数据有约10⁻⁹量级微小负节点值，实际最小值在验证面板中显示。曲面高度表示标量u，箭头表示局部对流系数(u,u)。
