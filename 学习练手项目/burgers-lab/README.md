# 二维Burgers平面演示

打开[二维演示](plane.html)，观察固定平面上高值区域的传播与扩散；颜色图和立体数值曲面同步显示同一组实际有限元解。

## 模型与方法

无源二维标量方程 `u_t+u(u_x+u_y)=0.02Δu`，单位正方形，零Dirichlet边界。左下方光滑局部峰为初值；1089节点、2048三角形，二维P1有限元、后向Euler、Picard迭代，80个实际时间步至t=0.8。网格始终固定；对流系数为(u,u)。

## 文件与复现

- plane.html：内置数值数据与LaTeX渲染的独立网页。
- plane_template.html：页面模板。
- solve_2d.py：真实数值求解与页面生成。
- results_2d.json：坐标、单元、全部时间步和验证指标。

在仓库根目录使用移动网格Python环境运行 `学习练手项目/burgers-lab/solve_2d.py`。外部依赖FEALPy；页面回放无需安装Python。渲染库由移动网格/tools/vendor提供。

## 验证与范围

峰值由1降至0.191028，峰位置从(0.3125,0.3125)移到(0.4375,0.4375)。最大非线性残量9.819e-10，边界误差0。当前新算例没有解析解，尚未做网格加密误差验证。曲面高度是解值，不是第三个物理空间方向或真实水面；箭头不是网格位移或粒子追踪。
